# Plantilla de cliente

/onboard copia esta carpeta a `clients/<slug>/`. No editar aquí datos reales.

Archivos que se generan (en orden):
1. brief.md          ← /onboard
2. audit-site.md     ← /audit-landing
3. competitors.md    ← /competitors
4. benchmark.md      ← /benchmark-interno
5. strategy.md       ← /strategy
6. roadmap.md        ← /roadmap
7. checklist.md      ← /roadmap (crea) · /weekly-review (mantiene)
8. log/YYYY-MM-DD.md ← /weekly-review, /build-campaign, /negatives
9. data/             ← keywords.csv, competitors-keywords.csv, negatives-*.txt, ads-*.md, exports
